# THE SMASHER

A retro-style, browser-based reaction game where you smash targets before time runs out. Built with HTML, CSS, and Vanilla JavaScript.

## Features
* **Retro Aesthetic:** Pixel-art typography and neon interface.
* **Fast-Paced Gameplay:** 30-second rounds to test your reaction speed.
* **Responsive Design:** Centered game container optimized for desktop browsers.
* **Visual Feedback:** Grid squares flash and change icons upon a successful hit.

## File Structure
* `index.html`: The structural layout and UI elements.
* `style.css`: Custom styling, grid layout, and color variables.
* `script.js`: Game logic, timer intervals, and score tracking.

## How to Play
1. Open `index.html` in any modern web browser.
2. Click the **START SMASHING** button.
3. Click on the squares when a target appears.
4. Each successful click increases your score.
5. Try to get the highest score possible before the 30-second timer hits zero.
